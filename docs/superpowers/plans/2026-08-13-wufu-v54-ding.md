# wufu-v5.4-ding 实现计划：买卖钉钉通知 + 账户 3% 止损通知

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 克隆 wufu v5.4 为 `wufu-v5.4-ding` 策略，策略自身买卖走 `log.notify` 发钉钉，引擎层 Matcher 账户 -3% 止损也发钉钉。

**Architecture:** 双通道。策略层：在克隆文件 `smart_order_target_value` 下单成功处追加 `log.notify`（含 pnl/持仓天数）。引擎层：`Matcher` 新增可选 `on_stop_loss` 回调，`runner.run_loop` 唯一接线注入 → `_emit_log(account_id, "notify", ...)` 走既有钉钉通道。

**Tech Stack:** Python 3.11 / FastAPI 模拟盘 runner / 聚宽式策略（jqcompat）/ pytest / ruff / mypy。

## Global Constraints

- 克隆源：`data/quant_strategies/42f91131.py`（五福v5.4 实跑版，ddd911f4 绑定；`data/` 不入 git）。

- 补跑/回放期间不推钉钉：`_emit_log` 对 `_replay_active_ids` 已抑制，本计划不新增抑制逻辑。
- 不动：ddd911f4 现有账户、`42f91131.py`、`wufu-v5.4.ptrade.py`、`_send_dingtalk_async` 包裹格式。

def _build_stop_loss_notify(stop: float, rec: dict) -> str:
    """账户止损（Matcher）钉钉通知正文。rec 由 Matcher.on_stop_loss 提供。"""
    pct = f"{rec['pnl_pct'] * 100:+.2f}%"

            f"卖出{int(rec['amount'])}份 价格{rec['price']:.3f} 佣金{rec['commission']:.2f} "
            f"盈亏{rec['pnl']:+.2f}({pct})")

```python
def _holding_trade_days(security, context):
    """持仓交易日数：买入日(含)到卖出日(不含)之间。取不到返回 None。"""
    entry = g._entry_date.get(security)
    if not entry:
        return None
    today = context.current_dt.date()
    if today <= entry:
        return 0
    try:
        days = get_trade_days(start_date=entry, end_date=today)
        return max(0, len(days) - 1)          # 减去卖出当日
    except Exception:
        return max(0, (today - entry).days)


def _notify_trade(security, name, action, amount, price, avg_cost, context):
    """买入/卖出钉钉通知。卖出时带盈亏与持仓天数，失败降级为 log.info。"""
    try:
        commission = abs(amount) * price * 0.0001
        if action == "卖出" and avg_cost > 0:
            pnl = (price - avg_cost) * amount
            pnl_pct = price / avg_cost - 1
            days = _holding_trade_days(security, context)
            days_str = f"{days}个交易日" if days is not None else "?天"
            log.notify(f"📤 卖出 {name}({security}) 数量{int(amount)} 价格{price:.3f} "
                       f"佣金{commission:.2f} 盈利{pnl:+.2f}({pnl_pct:+.2%}) 持仓{days_str}")
        else:
            log.notify(f"📥 买入 {name}({security}) 数量{int(amount)} 价格{price:.3f} "
                       f"佣金{commission:.2f}")
    except Exception:
        log.info(f"[notify] 成交通知组装失败 {security} {action}")
```
