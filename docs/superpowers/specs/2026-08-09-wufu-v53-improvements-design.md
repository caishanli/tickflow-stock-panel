# 2026-08-09 wufu v5.3 改进设计（风险调整后收益优先）

## 背景与目标

wufu v5.2（`backend/tests/fixtures/wufu_v52/wufu-v5.2.py`，聚宽文章克隆）为单持仓 ETF 动量轮动策略。基线回测（260401~260807，86 个交易日，本地 rqalpha jqcompat 引擎，10 万本金，佣金 0.01% + 最低 5 元 + 滑点 0.01%）：

| 指标 | 基线 v5.2 |
|------|-----------|
| 总收益 | +13.82% |
| 年化收益 | 44.69% |
| 年化波动 | 40.49% |
| 夏普 | 1.10 |
| 最大回撤 | -17.45%（2026-06-10） |
| 交易笔数 | 97 |

目标：在不大幅提高回撤的前提下提升风险调整后收益（夏普），全部改动可解释、可独立开关、逐项归因。

## 策略机制回顾（v5.2）

- 每日 13:00 对合并池（固定池 ~140 只 + 动态行业池 ≤300 只）计算动量得分 = 加权线性回归（25 日 log 价，权重 1→2 二次方）× 年化 × R²。
- 过滤：动量 ∈ [0,5]；正常期 R²>0.4；走弱期价格>MA10；量比（当日分钟量投影/近 5 日均量）<1.8；近 3 日无单日跌幅 >3%。
- 候选池：过滤后前 10 名中得分 ≥ 第 1 名 ×0.9。
- 13:05 卖出不在目标池的持仓，13:15 买入；无候选时持防御货币 ETF（511880）。
- 走弱期判定：沪深300/中证1000/创业板/中证A500 中 3/4 低于 MA10 进入（只交易全球/海外池），3/4 站上 MA10 或满 20 天退出。
- 分钟级固定止损：价格 ≤ 成本价 ×0.95 时卖出（仅 09:40-10:29/10:40-11:30/13:00-14:57 时段）。

## 改进设计（3 项，全部可独立开关）

### A1 盈利保护止损（默认开，`enable_profit_protect=True`, `profit_protect_trigger=0.05`）

- 现状：固定 -5% 止损只保护成本；浮盈后回调同样回吐到 -5%。基线 -17.45% 回撤发生于盈利积累后急跌。
- 改动：持仓**曾**浮盈 ≥ 阈值（默认 0.05）后，止损价上移至成本价（保本），按标的状态持久化（清仓后重置）。
- 实现：`minute_level_stop_loss` 内用 `g._profit_protected` 记录状态，触发后 `stop_threshold = 1.0`。
- 注意（实现陷阱）：若只按「当前 bar 浮盈≥阈值」判断，则与止损条件（价格≤阈值）互斥，永不触发——必须记录历史状态。

### A2 持仓宽容（调仓惰性，**默认关闭**，`hold_buffer=1.0`）

- 现状：持仓不在候选池（得分 < 第 1 名 ×0.9）即换仓；因过滤波动大，近 86 天换手 97 笔，反复横跳损耗费点。
- 改动（已验证负贡献）：持仓若仍通过全部硬过滤且得分 ≥ 候选池门槛 ×`hold_buffer`（0.9）时保留持仓。**260401~260807 回测夏普 1.10→0.98、收益 13.82%→12.48%，单独验证为负贡献；buffer=0.95 为无操作（窗口内无命中样本）。v5.3 默认关闭该开关。**
- 实现：`get_final_ranked_etfs` 第四步 retained 判定放宽（保留代码，默认 1.0 关闭）。

### A3 走弱期退出确认（默认开，`weak_exit_ma_lookback=20`）

- 现状：进入与退出均用 3/4 指数 vs MA10，弱市反弹即退出、随后再进入，池子反复切换。
- 改动：进入条件不变（3/4 低于 MA10）；退出需 3/4 指数站上 MA20（`weak_exit_ma_lookback=20`）。max_weak_days=20 保持。
- 实现：`check_a_share_weak_period` 退出分支改用退出均线周期（进入均线不变）。

- 设计文档：本文件。

## 验证协议（同引擎同窗口本地回测对比）

1. 全量窗口 260401~260807：基线（已有） vs A1 only vs A2 only vs A3 only vs v5.3 组合。
2. 对齐窗口 260401~260716：v5.3 复核（该窗口与聚宽 fixture 对齐，保证改进在可对齐区间同样成立）。
3. 性能门禁：260401-260716 回测 ≤120s（`test_wufu_backtest_perf.py` 口径）。
4. 验收标准（全量窗口）：夏普 ≥ 基线 +0.15 且 maxDD 不恶化；若 maxDD 改善 ≥3pct 则夏普不降即可。逐项改进若单跑有效但组合无效（或反之）需说明取舍。

### 结论与取舍

1. **A3（走弱期退出确认）是主要贡献者**：夏普 +0.42~+0.52，回撤同步改善（-16.48% vs -17.45%）。机制：2026-05~07 弱市期间 MA10 反复触发进入/退出，MA20 退出减少弱期⇄正常期池子来回切换与无效交易。进入条件不变，不改变原文「弱市切海外池」语义。
2. **A1（盈利保护止损）贡献有限但为正**：t=0.05 时窗口内唯一生效交易为 2026-07-28 豆粕ETF（曾浮盈≥5% 后回落，10:41 保本止损 2.1928 vs 原 13:05 卖出 2.1568，节省约 1850 元）。t=0.08/0.10 在窗口内无持仓达到阈值，为无操作。经济逻辑（浮盈后保本）标准且无害，默认 t=0.05。
3. **A2（持仓宽容）验证为负贡献**：保留宽持仓区间反而放跑跌幅（0.9 buffer 夏普 -0.12），v5.3 默认关闭（代码保留开关）。
4. **性能**：对齐窗口 v5.3 129.2s vs v5.2 128.3s（+0.7%），改动无实质开销；本机内存受限（OOM 风险）下基线本身已超 120s 门禁，属环境问题而非策略改动引入。
5. **稳健性说明**：验证窗口仅 4.5 个月；A1 效果集中在单笔交易、A3 效果集中在弱市时段，属机制层改进（非纯参数拟合），但对更长周期的外推需谨慎。

## 风险与限制

- 验证窗口仅 ~4.5 个月（分钟数据 2026-04-01 起覆盖），存在过拟合风险；3 项改动均为机制层（非纯参数），经济逻辑可解释，作为稳健性依据。
- 动态行业池每日变动、名称清洗规则、流动性阈值等未改动，保持 v5.2 行为。
