# 模拟盘净值曲线快捷时间范围筛选 — 设计

日期：2026-08-12，分支：fix/sim-profit-chart-date（继续沿用）

## 目标

量化模拟盘详情页「净值曲线」卡片增加快捷时间范围按钮：全部 / 一星期 / 1个月 / 3个月 / 6个月 / 1年。选择后曲线展示该窗口的收益曲线（区间归一化），并把「收益率」「盈亏」两张指标卡切换为区间值。

## 范围

- 仅 `frontend/src/quant/pages/QuantSim.tsx`（SimDetail 组件），无后端改动。
- 仅影响净值曲线卡片 + 5 张指标卡中的「收益率」「盈亏」；其余卡片（净值/现金/持仓市值）保持当前实时值。
- 持仓/成交记录/止损/日志 Tab 不受影响。

## 交互

- 按钮放「净值曲线」标题行右侧：`[全部] [一星期] [1个月] [3个月] [6个月] [1年]`，默认选中「全部」，选中态高亮（沿用现有 tab 按钮样式 `bg-accent text-white`）。
- 周期→日历天数：一星期=7、1个月=30、3个月=90、6个月=180、1年=365。
- 过滤口径：`dt >= 今天 - 周期天数`（日历时间，非交易日）。
- 窗口内数据点 <2 时（如刚建账户选「1年」）回退显示全部数据。

## 曲线计算

- 现逻辑：按天聚合 equity 取每日最后一点 → `stratPct`（相对 start_cash 累计%）/ `benchPct`。
- 新增：选「全部」时保持现逻辑；选具体范围时取窗口内数据，**区间归一化**：
  - `rel(i) = (1 + cum[i]/100) / (1 + cum[0]/100) - 1`，策略与沪深300 同法，曲线从 0% 起。
  - Tooltip「累计/当日」双列不变（当日仍用累计反推）。

## 卡片计算

- 选「全部」：现有逻辑（净值、总盈亏 `state.pnl`、总收益率 `net/start_cash-1`）。
- 选具体范围：
  - 收益率 = `(1+当前累计收益) / (1+窗口首日累计收益) - 1`
  - 盈亏 = `窗口末净值 - 窗口首日净值`（金额，正红负绿样式沿用）
  - 净值/现金/持仓市值 = 当前实时值不变。

## 实现要点

- SimDetail 内 `useState<'all' | 7 | 30 | 90 | 180 | 365>('all')`，派生 `windowed` equity 数组供 curve useMemo 与卡片计算复用。
- 复用现有 `dayMap` 聚合结果做窗口切分（先聚合后过滤，保持曲线口径一致）。
- 无新依赖。

## 验证

- 无头浏览器实测：切换各按钮，检查曲线 canvas 首点从 0% 附近起、收益率/盈亏卡片数值与窗口口径一致、「全部」恢复原值。
