# 70978ed5 策略 PTrade 原生版设计

日期：2026-08-19
分支：`feat/ptrade-70978ed5`

## 背景与目标

现状：策略库（data/quant_strategies/ + quant.db `strategies` 表）中的 `70978ed5`（五福v5.4，单持仓）是聚宽（JQ）版本，正被模拟盘账户 `7868a5ca` 使用。代码大量使用聚宽独有 API（`jqdata`/`get_current_data`/`attribute_history`/`get_all_securities`/`get_security_info`/`record`/`set_option`/`set_order_cost`），并直接 import 本地 `app.quant.jqengine.datasource.manager`，无法在真实 PTrade 平台运行。

目标：严格按照 `guojin-ptrade-api.docx` 定义的 API，将 70978ed5 改写成 PTrade 原生版，交付为新的策略库条目（可从前端选它跑回测/模拟盘），并提供引擎支撑与对齐门禁验证。JQ 原版文件不动。

## 方案（已确认）

方案 A：原生重写 + 引擎补齐 + rqalpha 对齐门禁。

1. 策略删掉全部 jq 痕迹与本地引擎注入，正文直接调用 docx 原生 PTrade API（`.SS/.SZ` 码、`run_daily(context, func, time)`、`before_trading_start`/`after_trading_end`/`handle_data`、`get_history`/`get_price`/`get_stock_status`/`check_limit`/`get_stock_name`/`get_etf_list`/`get_market_list`/`get_market_detail`/`order`/`get_position`/`get_positions`/`context.portfolio.cash`/`context.portfolio.portfolio_value`/`context.blotter.current_dt`/`context.previous_date`），无转换层。
2. 扩展本地 ptrade 引擎（`ptrade_api.py`，模拟盘 runner）与 rqalpha 引擎（`ptradecompat.py`，回测）+ loader 命名空间，补齐 docx 原生函数。
3. 新策略条目存回策略库（新 sid，名称「五福v5.4-ptrade」），源真相放 `tests/fixtures/70978ed5_ptrade/`。
4. 对齐门禁：同窗口跑 JQ 70978ed5 vs PTrade 版（rqalpha），断言逐笔成交一致 + 逐日净值零差；另加编译测试与无 jq API 清单测试。

范围：只做 70978ed5 这一支；既有 `wufu-v5.4.ptrade.py` / `dual_v54` 两版不动。

## Section 2 — 策略映射表（JQ → docx 原生 PTrade）

| JQ 写法 | PTrade 原生（均出自 guojin-ptrade-api.docx） |
|---|---|
| `.XSHG`/`.XSHE` 码 | `.SS`/`.SZ`（池/基准/指数/持仓键全部转换） |
| `set_slippage(PriceRelatedSlippage(0.0001), type='fund')` | `set_slippage(0.0001)` |
| `set_order_cost(OrderCost(open_commission=0.0001, min_commission=5), type='fund')` | `set_commission(commission_ratio=0.0001, min_commission=5.0, type='ETF')` |
| `set_benchmark("510300.XSHG")` | `set_benchmark("510300.SS")` |
| `log.set_level(...)` / `record(...)` | 删除（docx 无；`record` 改 `log.info`） |
| `run_daily(fn, time)` | `run_daily(context, fn, time)`（09:00→`before_trading_start`；15:10→`after_trading_end`；every_bar→`handle_data`；09:40/13:10×3 保留 `run_daily`） |
| `attribute_history(code, n, '1d', ['close'])` | `get_history(n, '1d', 'close', security_list=code, fq='pre')` |
| `get_current_data()[c].paused` | `get_stock_status([c], query_type='HALT')`（按日缓存 + 分块） |
| `get_current_data()[c].last_price` | `data[c].price`（handle_data 快照）+ `get_history(1,'1d','price', security_list=c)` 兜底 |
| `get_current_data()[c].high_limit/low_limit` | `get_history(1,'1d',['high_limit','low_limit'], security_list=c)`（日线字段，单标的列=字段名） |
| `get_price(codes, count, end_date, '1d', fields, panel=False)` | `get_price(codes, end_date=…, count=…, frequency='1d', fields=[...])`（docx 原生 `get_price`，本地引擎返回宽表 index=datetime, columns=PTrade 码） |
| `get_price(…, '1m', ['volume'])`（盘中分钟量） | `get_price(codes, start_date=…, end_date=…, frequency='1m', fields=['volume'])` |
| `get_all_securities(['etf']).index/display_name` | `get_etf_list()` + `get_stock_name(list)` / `get_market_list()`+`get_market_detail(mic)`（全市场枚举分块 200） |
| `get_security_info(sec).display_name` | `get_stock_name(sec)` |
| `context.portfolio.positions` / `.total_amount` / `.avg_cost` / `.closeable_amount` | `get_positions()` / `pos.amount` / `pos.cost_basis` / `pos.enable_amount` |
| `context.portfolio.available_cash` / `.total_value` | `context.portfolio.cash` / `context.portfolio.portfolio_value` |
| `context.current_dt` | `context.blotter.current_dt` |
| `order(sec, amount)` / `order_value(sec, val)` | 同名（docx 原生，返回 order id 或 None） |
| `from jqdata import *` / 直接 import DataManager | 删除（改走 `get_history`/`get_price` 原生取数） |

策略正文交易逻辑（动量评分、弱市判定、过滤、买卖分配、止损、T+1 检查）一行不改，只替换为原生 API 访问。

## Section 3 — 引擎扩展（ptrade_api.py + ptradecompat.py + loader）

两个引擎 + loader 补齐 docx 原生函数：

| 函数 | 说明 |
|---|---|
| `get_price` | 支持 count+end_date（日线）与 start_date+end_date（分钟）；返回宽表（index=datetime, columns=PTrade 码）；单标的单字段列=字段名；单标的单字段返回 DataFrame 一列。 |
| `check_limit` | 返回 `{码: int}`，-2 触板跌停 / -1 跌停 / 0 平 / 1 涨停 / 2 触板涨停。 |
| `get_stock_info` | 返回 `{码: {stock_name, listed_date, de_listed_date}}`。 |
| `get_snapshot` | 返回 `{码: {up_px, down_px, last_px, ...}}`（交易场景真实快照；回测回退日线字段）。 |
| `order_target` / `order_target_value` | 按目标数量/目标市值调仓（100 股整手）。 |
| `get_all_trades_days` / `get_trading_day_by_date` | 交易日历查询。 |
| `get_etf_info` | 返回 `{码: 名称}`（ETF 名称，缺失回退代码）。 |

格式保证（延续 dual_v54 先例）：
- `get_history`/`get_price` 多标的宽表（columns=PTrade 码，index=datetime）；单标的单字段列=字段名。
- `get_positions()` 恒 `{PTrade码: Position}`，Position 恒含 `amount`/`enable_amount`/`cost_basis`/`last_sale_price`。
- `handle_data` 的 `data` 恒 `{PTrade码: obj}`，obj 含 `close/price/volume/money`。

## Section 4 — 调度设计（严格保留 13:10 同点）

| 原版 JQ 调度 | PTrade 原生映射 | 说明 |
|---|---|---|
| `run_daily(morning_routine, 09:00)` | `before_trading_start(context, data)` 调 `morning_routine` | 09:00 在 PTrade 分钟回测不合法；盘前语义一致 |
| `run_daily(check_weak_period_daily, 09:40)` | `run_daily(context, check_weak_period_daily, time='09:40')` | 合法时段 |
| `run_daily(afternoon_routine, 13:10)` | `run_daily(context, afternoon_routine, time='13:10')` | 同点 ×3，按注册顺序执行 |
| `run_daily(sell_routine, 13:10)` | `run_daily(context, sell_routine, time='13:10')` | 同点 ×3 |
| `run_daily(buy_routine, 13:10)` | `run_daily(context, buy_routine, time='13:10')` | 同点 ×3 |
| `run_daily(reset_daily_flags, 15:10)` | `after_trading_end(context, data)` 调 `reset_daily_flags` | 收盘后重置缓存（该函数实际只重置未用字段，纯语义保留） |
| `run_daily(minute_level_stop_loss, every_bar)` | `handle_data(context, data)` 内按分钟窗口判断调用 `minute_level_stop_loss` | every_bar 不存在于 docx，handle_data 为必选钩子 |

- `run_daily` 任务总数 = 4（09:40 + 13:10×3）≤ docx 限制 5。✓
- 盘中行情统一由 `handle_data` 的 `data` 快照（docx 标准 `{码: SecurityUnitData}`，含 close/price/volume/money）+ 模块级 `_BARS` 缓存；`before_trading_start`/`after_trading_end` 的 data 为保留字段，注入空快照（沿用 dual_v54 先例）。

## Section 6 — 风险与取舍

- **同点时序**：13:10 三个任务在真机 PTrade 的触发顺序官方未明文保证——本地两个引擎按注册顺序执行，对齐门禁覆盖本地；真机部署前需在国金平台实测顺序，必要时退化为错峰（记录为已知风险，不在本分支处理）。
- **get_history/get_price 返回形态**：docx 分 py3.5/py3.11 两种宽表——本地引擎固定 py3.5 变体（columns=码）并在单标的时列=字段名；策略代码只按该形态切片，真机若版本不同需微调。
- **性能**：动态池全市场枚举与流动性过滤从 DataManager 内存缓存改为 `get_price`/`get_history` 分块（200/块）网络取数，回测变慢可接受（门禁窗口有限，与 v5.2 同量级）。
- **范围收口**：只做 70978ed5 这一支；既有 wufu-v5.4.ptrade / dual 两版不动。
